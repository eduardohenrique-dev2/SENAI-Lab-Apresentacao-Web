# SENAI Lab — Apresentação Web

Apresentação web institucional do **Sistema de Gestão de Demandas do SENAI Lab — SENAI Afonso Greco**.

## Recursos

- 20 seções em formato de slides
- HTML + CSS + JavaScript
- Navegação lateral
- Teclas de seta, PageUp/PageDown, Home e End
- Tecla **F** para tela cheia
- Contador de slides e barra de progresso
- Layout responsivo
- QR Code incorporado no próprio HTML
- Link direto para o sistema oficial

## Como executar

Basta abrir `index.html` em qualquer navegador moderno. Não exige instalação, build ou servidor.

## Sistema oficial

https://senai-lab-afonso-greco.vercel.app/

## Estrutura

- `index.html` — conteúdo da apresentação
- `styles.css` — identidade visual e responsividade
- `script.js` — navegação e modo apresentação
