Fila de produção

Quando o equipamento é o mesmo, existe uma ordem definida.

Para demandas do mesmo equipamento e da mesma data, quem solicitou primeiro fica na frente. É uma regra simples e fácil de explicar.

mesmo equipamento + mesma data = ordem de criação
